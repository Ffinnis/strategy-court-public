## UI copy and typography

- Write interface copy in sentence case and render it in the app's primary sans-serif typeface.
- Never transform interface copy to uppercase in markup or CSS. Do not use `text-transform: uppercase` for labels, navigation, metadata, buttons, or badges.
- Do not use tracked monospaced micro-labels as decoration. When context or status needs emphasis, use a real component such as a badge, tab, status mark, or labeled control in the primary sans-serif.
- Preserve uppercase only when it belongs to the underlying data or established name, such as ticker symbols and acronyms.

## UI layout

- Use as few cards as possible. A card must represent a genuinely independent object or action, not merely decorate a section.
- Prefer flat sections, spacing, typography, dividers, tables, and disclosures over nested containers.
- Do not place a card inside another card unless the nested surface has an independent interaction model that cannot remain legible otherwise.
