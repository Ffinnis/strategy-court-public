# Revised visual direction

The first selection overvalued useful patterns and undervalued visual execution. This brief supersedes that selection as an aesthetic recommendation. The earlier functional inventory remains research, not an approved visual direction.

The user's accepted example is Jeet's [LLM comparison panel](https://collectui.com/designs/accordion-ui-design-inspiration/1f0bdcc2-9127-42ee-b3eb-69b4c212d890), shown as pick 2 in the original response. It is reference 17 in the original full inventory.

## What makes that reference work

- A pale frame and a crisp inset working surface establish depth with very little contrast.
- A clear type hierarchy separates names, secondary metadata, and exact values.
- Rows, bars, and numbers align to repeatable columns.
- Hairline separators and low visual noise make the colored marks stand out.
- Expansion stays attached to its row, preserving the visual relationship.

The rounded outer frame is appropriate for an independent inspector. It is not a reason to wrap every section of Strategy Court in a card.

## Three closer references

All three are by Jeet. That is intentional: they share the visual treatment the user liked. They are a coherent next shortlist, not a claim that every example is a universally perfect design.

## How this changes our design work

Start with one representative run-detail screen. Establish a consistent type scale, numeric alignment, spacing rhythm, separator weight, and contrast hierarchy before adding motion. Keep the app's primary sans-serif and sentence case. The references' monospaced metadata and uppercase micro-labels should not transfer.

For the current dark direction, translate the relationships between surfaces rather than invert the screenshot. Keep the page quiet, give the active working area a slight contrast step, and reserve stronger separation for a floating inspector. Do not multiply cards across the workspace. Color should identify a series, selection, or status, and never carry meaning alone.

Use motion to preserve context or communicate a real event: connected expansion, a completed check, a moved limit, or a newly populated region. Avoid ambient bouncing, looping success animations, and fake live activity. Reduced-motion mode must show the same final information immediately. Exact durations and easing have not been measured from these videos; no inferred timings are presented as source facts.

## What did not make this shortlist

I rechecked complete layouts by rico, Ayda Oz, Michael Nowak, Marcel, and emil. Some contain useful individual details, but I would not promote those inspected layouts as the app's visual benchmark. Issues included decorative chart weight, very low-contrast text, excessive badges, and reliance on boxed modules. No full-app composition is endorsed in this revision.
