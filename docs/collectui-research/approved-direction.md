# Approved visual references

On September 1, 2026, the user approved the revised shortlist and asked for additional animations and more distinctive UI elements. This approval applies to the references below as visual direction. It does not mean that every later candidate or every detail within a source should be copied.

| Approved reference | Decision it informs |
| --- | --- |
| [Jeet's comparison panel](https://collectui.com/designs/accordion-ui-design-inspiration/1f0bdcc2-9127-42ee-b3eb-69b4c212d890) | Precise row alignment, a restrained inset working surface, fine separators, exact numeric alignment, and color used for data |
| [Sub-Agent Fanout](https://collectui.com/designs/ai-agents-ui-design-inspiration/54269511-7c19-4ab8-8f3c-24dea577456b) | Fine connecting lines, small meaningful nodes, and a diagram paired with aligned result rows |
| [Sandbox Limits](https://collectui.com/designs/modal-ui-design-inspiration/e3f1230d-4674-4076-91ee-54599eed8080) | Directly labeled controls, matching chart geometry, restrained depth, and warnings concentrated at the affected limit |
| [Life in Weeks](https://collectui.com/designs/infographic-ui-design-inspiration/0b5c413e-fb9b-4928-a620-f6c4cc66081f) | A dense field of uniformly spaced marks, one dominant visualization, and a quiet legend and summary row |

The original broad shortlist was superseded after the user rejected its visual quality. Its functional suggestions remain research, not approved styling.

Keep Strategy Court's sans-serif, sentence case, accurate values, and flat page structure. The next work should translate the approved visual relationships into the app's existing dark direction. Do not copy unrelated branding, decorative card grids, uppercase micro-labels, or monospaced interface decoration.
